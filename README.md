# Opportunities for Jamaicans — career preparation concept

**Status:** Early, independently developed working prototype for discussion. This is not an official partnership announcement.

This repository contains a mobile-friendly concept for an **Opportunities for Jamaicans** career preparation experience, developed by **Beginning Concepts** as a proposed technology partner.

The goal is to complement—not replace—the existing [Opportunities for Jamaicans WhatsApp channel](https://whatsapp.com/channel/0029VbBwdL5JZg48LDSJOY14), by helping followers prepare to apply for the jobs, scholarships, and training opportunities shared there.

## Current prototype

- Fully responsive landing page reflecting the existing yellow-and-black *Opportunity Just Ahead* channel identity in a simplified CSS illustration.
- Free résumé editor with live preview, fictional example profile, save-on-this-device option and PDF output using the browser’s Print / Save as PDF command.
- Basic editable cover-letter draft generator and copy action.
- Official WhatsApp channel link.
- Clear “working concept” identification and Beginning Concepts technical credit.

## Privacy

The prototype runs entirely in the browser and does not send résumé content to an application server. The optional Save button uses localStorage on that device, which is **not encrypted storage**. Users on shared devices should avoid saving personal details. Export and review your PDF before sharing it.

No accounts, external APIs, analytics, employer submissions, AI model calls, or personal-data backend are currently enabled.

## Preview / hosting

Open `index.html` in a browser locally to test the working prototype. GitHub Pages is **not automatically enabled** merely by adding these files. To deploy, use the repository's Settings → Pages and select deploy from branch `main`, folder `/(root)`, if your account permissions allow it.
